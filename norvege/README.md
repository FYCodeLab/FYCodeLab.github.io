# Norvège 2026 — Trip Guide Prototype

Prototype of an **online trip guide**: an interactive itinerary for a family road trip in Norway
(Tromsø → Bodø, 28 July – 7 August 2026).

![Screenshot](screenshot.png)

## What it does

- Interactive Leaflet map with **119 points of interest** (viewpoints, villages, curiosities)
- Day-by-day itinerary with search and category filters
- Accommodation markers with dates, favorites, live route info (OSRM)
- Phone-friendly, with a "Où suis-je ?" geolocation button

## Status

Prototype — not a standalone repo yet. A single self-contained `index.html`
(`n2.html` is an older draft).
