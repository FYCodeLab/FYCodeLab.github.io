WHAT THIS SHOWS

This is one artificial neuron performing a linear regression. Each normalized input is multiplied by a weight, the weighted values are summed, and the bias is added to produce the predicted shoe size.
TEACHING POINT

If the true relationship between age, hand size, height and shoe size is approximately linear, this single neuron can learn it. Hidden layers become useful when the relationship cannot be represented adequately by one linear combination.
