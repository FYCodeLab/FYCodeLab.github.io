# SEPIA — Website Template v1

Template for the SEPIA website (Service d'Étude des Prions et des Infections Atypiques, CEA Institut de biologie François Jacob, Fontenay-aux-Roses), following the exact CEA Jacob UI of the IRCM Plateformes page.

## What it is

- Single self-contained `index.html` (4.3 MB, images inlined)
- Four pages: Présentation, Laboratoires L4PA / LIDT, Plateformes et équipements, Publications et brevets
- Plateformes lists only the three SEPIA facilities: prion animal facility, 120 m² L3 prion laboratories, and 3D BIO DIVE imaging, each with its own detail page
- Publications include the two verified 2020 papers (SEPIA–CellTechs / Gly-CRRET brain organoids, and the Acta Neuropathologica 2020 vCJD propagation paper), plus the existing citations (Lasmézas 1996, Moynagh 1999, Deslys 2001, Fichet 2004, Gill 2013)

## Status

Template / demo. Every externally sourced photo is plastered with a DEMO overlay on the image itself — they are illustrations, not SEPIA's own facilities.
