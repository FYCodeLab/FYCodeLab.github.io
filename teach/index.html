Interactive tutorial

I am going to teach you how to use this site.

Follow the short steps on the left, then try Teachable Machine directly in the embedded window.

How we will use it

1
Choose a project

Select an image, audio, or pose project depending on what you want to train.

2
Add examples

Give the model several examples for each class you want it to recognize.

3
Train your model

Start training and let Teachable Machine learn the differences between your classes.

4
Test and export

Try new examples, check the predictions, then export your model when you are satisfied.
